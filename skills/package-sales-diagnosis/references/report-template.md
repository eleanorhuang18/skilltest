# 诊断报告模板

一页纸，顺序固定。删掉示例文字，换成实际数据。所有数字带单位与口径。

```markdown
# <套餐族> 销售诊断 · <YYYY-Qn>

## 结论

1. **性质**：<真下滑 / 结构性下滑 / 属于正常波动>，本季净收入环比 <±x%>，同门 <族A/族B> 分别为 <±x%>/<±x%>。
2. **主矛盾**：<规模 / 变现 / 使用 / 结构> 层失守，具体表现为 <一句话>。
3. **主因**：<原因一>（置信度高）、<原因二>（置信度中）。

## 证据

| 指标 | 本季 | 上季 | 环比 | 同门中位 | 判断 |
| --- | --- | --- | --- | --- | --- |
| 净收入 `ra_net` | | | | | |
| 用户月数 `rgb` | | | | | |
| 代理 ARPU | | | | | |
| 人均流量 | | | | | |
| 5G 流量占比 | | | | | |

## 贡献分解

| 区域 | 上季收入 | 本季收入 | 变化 | 贡献度 |

| --- | --- | --- | --- | --- |

已排除：<反证一>、<反证二>。

## 边界

本结论基于代理口径（数据源无订单量字段）。确认因果还需：资费表、竞品价格、渠道激励政策。
```

## 写作要求

- 结论放最前，三行说完；不要写"首先我们来看"。
- 每个判断后面跟数字，不写"大幅""明显"这类无法核对的词。
- 归因最多 3 条，待验证最多 2 条；超过说明没想清楚。
- 动作必须是本周或下周能开始的，不写"加强渠道管理"这种没有主语和验证的句子。
- 数字有异常（负数、极端值）先核实再写，不要直接放进报告。
